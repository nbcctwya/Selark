[model-discovery-verification.json](model-discovery-verification.json)。

## 行为

`selark connection add ID --provider openai --interactive` 在模型留空时，
使用安全输入的 Key 查询当前连接的模型列表，保存上游返回的全部合法模型标识。
非交互命令省略 `--models` 时行为相同。复用既有发现实现、超时、分页、大小限制、
脱敏与并发配置检查，不跟随重定向、不自动重试，不发起模型生成。

- 手动填写 `--models` 时保留用户选择；`--no-discover` 允许仅保存本地配置。
- 失败保留连接与 Key，返回退出码 1，说明使用 `connection discover ID` 重试或手动配置。
- 自动发现不按上游排序任意挑选默认调用模型；显式 `--default-model` 必须出现在返回列表中。
- Token Plan 预设、ChatGPT OAuth、已有连接更新 Key 的行为保持不变。
- Dashboard 首页资源池可滚动查看全部连接，修复第六个及之后连接被截断的问题。
  Dashboard 本身仍严格只读，不会启动模型发现。
