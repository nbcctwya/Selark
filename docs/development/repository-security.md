# 仓库发布检查

源码仓库保存代码、占位配置和已审阅的合成或脱敏结果。真实配置、凭据、数据库、备份及原始请求报告留在用户目录、Git 忽略目录或系统临时目录。

## 检查入口

在主仓库根目录执行：

```bash
python scripts/check_repository_security.py
```

该离线脚本检查当前 Git 仓库已跟踪文件、未被忽略的新文件，以及被强制加入 Git 的私有文件；输出文件、行号和规则名，不输出命中的内容，也不读取用户配置或联网。
它检查常见凭据格式、明文认证字段、本机绝对路径及忽略规则，已纳入 CI。它不遍历历史提交，也不递归扫描子模块；Selark-Web 的源码应在其自身仓库范围内单独检查。

## 文件位置

[.gitignore](../../.gitignore) 覆盖用户配置、密钥、数据库、日志、备份、恢复记录及浏览器会话文件。
原始验收输出写入 `reports/`、`.private/` 或系统临时目录；审阅后的 Markdown 与脱敏 JSON 放在 `docs/verification/`。
配置占位模板放在 `config/`，外部程序和策略模板放在 `examples/`。

忽略规则不会移除已提交的内容，当前文件检查也不等于历史检查。模式检查无法识别所有自定义令牌、编码或压缩内容，发布前仍需查看实际差异。

2026-10-31 的文件与 Git 历史检查范围、结果和已知边界保存在 [历史验收记录](../verification/repository-security-2026-10-31.md)。
