Selark 本机自用修复验收，2026-11-01
=================================

已修复检查报告中的 SEC-01、SEC-02，并完成 DEP-01 构建依赖升级。
修复已安装到本机日常使用的 pipx Selark。配额账本性能优化 PERF-01 按自用场景暂缓，
没有调整账本结构、配额结算规则或真实模型配置。此次真实提供商调用为 0。

| 修复项 | 最终行为 | 验证证据 |
| --- | --- | --- |
| 请求入口 | 在读取正文、占用生成名额前鉴权；鉴权查询另有有限并发容量 | 3 轮共 60 个不完整 TCP 请求立即返回 401，生成名额占用为 0，正常调用均返回 200 |

| Dashboard 会话 | 使用按 origin 隔离的 sessionStorage 和显式 `X-Selark-Session`；不再下发管理 Cookie | 真实 Chromium 访问其他本机端口，未发送 Cookie 或会话请求头；重放读取及修改均返回 401 |
| 正常面板操作 | 保留刷新、模型启停、默认模型确认、版本冲突检查及过期清理 | 页面刷新保持登录；正常修改返回 200；过期后清除会话和页面数据；手机及深浅色模式通过 |
| 浏览器限制存储 | 回退为页面内存会话 | 禁用 sessionStorage 后仍能登录和修改模型，过期后正常清理；此模式刷新需新的管理链接 |
| 构建依赖 | setuptools 84.2.1，构建范围 `>=84.1,<85` | wheel、sdist、全新环境安装及 pip check 通过；32 个锁定依赖的 OSV 查询无匹配公告 |

核心改动位于 [app.py](../src/selark/app.py)、[dashboard.py](../src/selark/dashboard.py)
和 [app.js](../src/selark/dashboard_assets/app.js)。请求总时限、正文大小上限、调用方配额、
派发前撤销检查、Dashboard 同源限制、CSP 和写入前会话复查均保留。
页面使用凭据省略和同源请求模式，并拒绝重定向；管理凭据不会作为环境 Cookie 自动发送。

自动回归共 **848 项通过**，耗时 74.19 秒，只有一条既有 Starlette/httpx 弃用提示。

新增 9 项回归覆盖缺失、错误、重复或撤销令牌，错误认证方案，正文读取前拒绝错误类型，
鉴权拥塞与取消释放，以及正文接收期间撤销令牌和管理会话显式请求头边界。

`Content-Type: application/json`，以继续验证 1 MiB 正文上限返回 413。
