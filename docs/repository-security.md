## 自动检查与范围

```bash
python scripts/check_repository_security.py
```

该离线脚本扫描已跟踪文件和未被忽略的新文件，并检查被强制加入 Git 的私有文件。
命中常见凭据格式、明文认证字段、本机绝对路径或忽略规则时返回非零退出码，
不会显示匹配的敏感值，也不读取用户配置或联网。已纳入 GitHub Actions，并有隔离回归测试。
此脚本不是完整的秘密识别系统；自定义令牌格式、编码或压缩内容仍需要人工审阅。

`.gitignore` 不会删除已提交的内容。历史提交中曾包含上述本机路径和中转服务地址，
本次没有重写 Git 历史，所以旧版本中仍保留这类非凭据元数据。
本轮历史扫描未发现真实密钥或令牌，但无法保证识别所有未知或已经废弃的凭据。
